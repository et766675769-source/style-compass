让 AI 有设计品味

Style Compass 把你认可的高审美案例，蒸馏成介质无关的视觉规范——同一套品味，让 AI 在网页、PPT、UI、平面里都做出高级效果。

Core Principle
01

规范与介质解耦

风格库只存视觉原语（色彩比例、层级、留白占比），不写死介质参数。

02

审美可参数化

每条规范落到数值与边界条件，让 Agent 能稳定复现，而非靠形容词。

03

案例蒸馏

从你收藏的好设计逐张提炼，保留你的直觉词，升维成可执行规范。

How it works

三步把审美交给 AI

1

蒸馏模式

把收藏的案例逐张标注成「案例卡」，聚类成风格文件。

2

应用模式

按需求锁定风格，提取设计 token，沿用整套视觉原语。

3

介质落地

用介质映射表把 token 翻译成目标介质的具体参数。
