> 目的：验证 skill 的核心主张——**同一套视觉原语，跨介质都能成立**；并实测跨模型 / 跨 agent 可移植性。

## 二、跨模型 / 跨 agent 适用性验证

用一个**独立 agent 实例**（无主对话上下文）仅凭 skill 文件路径完成任务，模拟"另一个 agent / 另一模型消费该 skill"：

- **自包含性**：子代理仅读 `SKILL.md` + `style-dark-glass.md` + `medium-mapping.md`，独立判断走"应用模式"，无需求助补充信息。✅
- **规范落地**：逐项应用了 style-dark-glass 介质映射表 PPT 列的参数（16:9、标题 44–60pt、正文≥24pt、12 列、玻璃浮层），并叠加 medium-mapping PPT 章。✅
- **无模型/框架绑定**：全部为自然语言 + Markdown 表格，无代码、无专用协议、无 OpenRouter 等依赖，跨 agent 可移植。✅

### 验证发现的 3 个可打磨点 → 已修复 2 个

1. **PPT 辅助档与 24pt 可读底线的冲突**（真缺口）→ 已在 `medium-mapping.md` PPT 章补「字号档位与可读底线的化解规则」（并入上一档 / 整体放大，禁为精致压字）。✅ 已修
2. **PPT 材质圆角无绝对值**（真缺口）→ 已在 `medium-mapping.md` PPT 章补「材质与圆角基准」（锋利2–4 / 适中8–12 / 圆润14–20 / 极圆28+），各风格 PPT 列的"玻璃形/圆润"从此有具体落点。✅ 已修
3. **`ai-tells.md` 引用未内联**（设计权衡，非缺陷）→ skill 采用**渐进式披露**（skill-creator 推荐），反模式清单按需加载省 context；子代理未主动读该文件所致，保留现设计。
