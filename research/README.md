# research/ — 方法论与设计依据

本目录存放 Style Compass 的方法论、设计依据与决策记录，供贡献者与使用者阅读。

## 为什么需要"介质无关"这一层

主流设计类 Agent 技能把规则写死在某一介质上（多数是前端/CSS）。但"好看"的判断——
色彩比例、层级节奏、留白占比、对齐纪律——本质上与介质无关：
一张海报的"大标题 + 大留白"与一个网页 hero 的"大字 + 空旷版式"是同一个审美决定。

把规范拆成「介质无关原语 + 介质映射」带来三个好处：
1. **一套风格库服务所有产出**（网页/UI/PPT/平面），维护成本线性；
2. **蒸馏素材不限介质**——从一张好海报学到的呼吸感可以迁移到 PPT；
3. **Agent 不会被具体 API/画布带偏**，先决策"气质"，再落地"参数"。
