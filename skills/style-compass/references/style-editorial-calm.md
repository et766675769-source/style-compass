# Style: editorial-calm（编辑式留白 · 冷调克制）

## 1. 气质一句话
杂志编辑感的留白型版面：大字大而疏、画面空旷克制、低饱和中性，冷静、高级、可信。文字本身即主视觉。

## 2. 适用信号
- 触发：高端地产/建筑落地页、编辑/杂志式品牌官网、作品集封面、报告与演示、需要"冷静高级"的场景。
- 受众与情绪：专业人士、决策者；可信、从容、有品味。
- 不适用：高密度数据后台、年轻活力/娱乐营销、需要撞色刺激的场景（另选）。

## 3. 色彩宪法
- **中性基底**：暖白/米白/浅灰为主，文字用近黑炭色（拒纯黑 `#000`）；低饱和全程。
- **表面层级**：白卡比底略深一档；分隔优先靠留白，其次细线，最后底色块。
- **强调色**：上限 1，低饱和、深色调（黠红/黛绿/藏蓝/正红少量）；只给语义与极少量点缀，禁整块强调区。
- **禁用**：AI 紫蓝渐变、霓虹、荧光、高饱和撞色。
- **明暗双模式**：支持；深色版用暖炭底 + 纸色字，反方向阴影，禁简单反色。

## 4. 对比节奏
- **字号阶梯比例** ≈ 显示:标题:正文:辅助 = 4 : 2 : 1 : 0.6。
- **字重**：大标题"大而细 + 收紧字距"制造张力；正规则；辅助加宽字距微缩。
- **行高字距**：标题行高紧（≈1.0–1.1），正文舒展（1.5+）；标题字距收紧。
- **正文行宽**：40–65 字符舒适区。
- **字体气质**：衬线用于标题/引语（编辑感来源），无衬线用于 UI/正文；中文优先思源宋体/黑体体系。

## 5. 留白与呼吸
- **密度档位**：画廊级，填充 ≤ 40%，宁可空不挤。
- **区块间距**：以大标题字高的 1.5–2 倍作大区间隔。
- **关键元素**：标题、CTA、核心图表四周留白不可压缩。
- **呼吸节奏**：多页时"疏页 ↔ 密页"交替，禁全程同密度。

## 6. 栅格与对齐
- **对齐范式**：左对齐为主 + 偶发居中仪式感（封面/引语页）；反对无理由全局居中。
- **破格**：允许越出栅格一档制造张力，每屏最多一处，且有意为之。
- **分组优先序**：留白 > 细线 > 底色。
- **版面分割**：图文比例倾向 5:5 或 6:4（非对称更佳）。

## 7. 材质与语气
- **曲率**：锋利到适中；卡片圆角克制（近直角），按钮轻微；禁胶囊大容器。
- **线条**：1px 细线、比底色深一档灰（非纯黑），只分隔不框每块。
- **阴影**：默认无影；交互抬升层用极淡大扩散低对比影，观感"悬浮而非发光"。
- **图形语言**：图标细线型、圆头/平头统一；图片去饱和 10–20%、统一色调；可用极淡纸纹颗粒。
- **动效**：缓。入场淡入 + 极短位移（8–16 感知 px），缓入缓出；禁持续动画与弹跳过猛。

## 8. 动效与语气
- **三档**：缓。仅页面过渡 + 关键元素淡入；PPT 仅页面切换。禁滚动劫持与持续动画。

## 10. 本风格反模式
- 留白做成空洞（无对齐参照，像没做完）→ 所有空白对齐到栅格或有意的比例。
- 衬线标题 + 无衬线正文层级配错（衬线成了正文）→ 气质颠倒。
- 每块内容都加细边框 → 边框成噪音；能靠留白就不加线。

- [ ] 填充 ≤40%，关键元素无挤压
- [ ] 对齐统一、破格 ≤1 处且有意图
