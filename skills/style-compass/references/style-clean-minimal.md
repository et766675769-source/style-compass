# Style: clean-minimal（素雅极简 · 干净呼吸）

## 1. 气质一句话
米白/浅底上大量留白 + 大号黑体标题 + 单一低饱和强调色，干净、可信、有呼吸感，像是"极简生活方式的消费品牌"。

## 2. 适用信号
- 触发：消费电子、生活方式、保险/金融、旅行、产品官网；需要"干净、可信、高级但不冷"的场景。
- 受众与情绪：大众到中产；清爽、安心、克制。
- 不适用：暗夜沉浸/戏剧感、高饱和撞色刺激、怪诞艺术（另选）。

## 3. 色彩宪法
- **中性基底**：米白/白灰为主，文字近黑；全程低饱和、明亮。
- **表面层级**：白卡，极淡分隔；卡片靠留白与极细分隔线组织。
- **强调色**：上限 1 个低饱和色调（橙/蓝/绿之一），只给 CTA、数据点睛；禁大面积强调。
- **禁用**：霓虹、荧光、渐变色、高饱和撞色。
- **明暗双模式**：默认浅色；深色版用深灰底 + 纸色字，保持低饱和。

## 4. 对比节奏
- **字号阶梯比例** ≈ 显示:标题:正文:辅助 = 3 : 1.6 : 1 : 0.7。
- **字重**：大黑体标题 + 灰色副文（明度差用灰阶），靠字号差而非字距。
- **行高字距**：正文舒展（1.5–1.7）；标题标准到微紧。
- **正文行宽**：50–70 字符。
- **字体气质**：清爽几何/现代无衬线；标题可略粗；数字 tabular。

## 5. 留白与呼吸
- **密度档位**：日常到画廊级，填充 35–50%；关键区块大量留白。
- **区块间距**：大而规整，同类间距一致。
- **关键元素**：产品图、标题、CTA 四周留白充分。
- **呼吸节奏**：平滑均匀，无需强疏密交替。

## 6. 栅格与对齐
- **对齐范式**：居中或左对齐为主；规整、对称、易读。
- **破格**：基本不允许；追求秩序感。
- **分组优先序**：留白 > 极细分隔线 > 底色。
- **版面分割**：居中构图或简洁栅格；圆角图/胶囊按钮常见。

## 7. 材质与语气
- **曲率**：适中到圆润（克制）；卡片/按钮中等圆角。
- **线条**：极细或无线；分隔用淡灰细线。
- **阴影**：极淡或无；产品图用柔和投影。
- **图形语言**：线性图标 + 圆角产品图；图片干净明亮；无纹理颗粒。
- **动效**：静到缓。淡入 + 轻微上移；禁持续动画。

## 8. 动效与语气
- **三档**：静/缓之一。仅淡入与 hover 反馈，克制零打扰。

## 10. 本风格反模式
- 留白过度显得空洞 → 关键区需有焦点（产品/标题）。
- 强调色用第二个 → 破坏"单点"克制。
- 大量卡片堆叠 → 能靠留白就别加框。
