# 介质映射手册（medium-mapping）

> 用途：应用模式第 4 步。把风格文件的**介质无关 token** 翻译成目标介质的落地参数。
> 读法：先定位你的介质章节，把风格 token 逐项套入该章模板；该章的"质量坑"与"交付检查"是硬性要求。
> 本文只给"通用翻译基准"；一套风格若有特殊决策，以该风格文件的介质映射表为准。

## 翻译总原则

1. **比例优先于像素**：风格文件给的是比例关系，介质映射负责把比例换算成该介质的具体尺寸阶梯，换算完保持比例不被破坏。
2. **每个介质有安全默认**：下文每章给出的区间是"不会错"的起点，风格要更极端就按风格走，但不得跌破可读性下限。
3. **换介质 = 换容器，不换气质**：同一套 token 在 PPT 上体现为留白页边距，在网页上体现为区块间距，在平面上体现为版心——气质一致、载体不同。

## A. 网页 / Web（HTML+CSS）

### 画布与单位
- 基准视口 1440×900（桌面）、390×844（移动）；断点按内容换行需求定，不硬凑流行断点。
- 用相对单位与 `clamp()` 让字号阶梯随视口伸缩；间距用刻度尺（如 4/8/16/24/48/96 的倍数关系），全页统一。
- 容器宽度取整段阅读的最佳行宽推导（正文 60–75 字符），页面级容器 ≤ 1280px 为常见默认。

### 字体
- 优先 Google Fonts / OFL 字体；商用字体必须给授权链接或换 OFL 候选。
- 每页 ≤ 2 个字体族（如 1 衬线 + 1 无衬线），等宽仅用于代码/数据。

### 颜色
- 用 HSL/CSS 变量表达四层色板，文字色满足 WCAG AA（正文 ≥ 4.5:1）。
- 深色模式不得简单反色：单独配一套明度与阴影。

### 质量坑（本介质特有）
- 禁满屏卡片海：能靠留白与细线分组就不要每块一个盒子。
- 首屏（hero）禁 `100vh` 引发的移动端跳动——用 `100dvh`。
- 禁在滚动容器上做常驻动效；动画只动 `transform`/`opacity`。
- 占位图禁裸 Unsplash；用可靠占位（picsum seed 或自绘 SVG），真实感优先。

### 交付检查
- [ ] 响应式断点下无横向滚动、无元素溢出
- [ ] 交互态齐全（hover/active/载入/空/错误）
- [ ] 深色模式（若适用）独立配过色
- [ ] 依赖在 package.json 中并给出安装命令

## B. 应用 UI / 桌面与移动软件

### 画布与单位
- 字号与间距用 pt（Apple）/ sp（Android）语义：正文 ≥ 15pt/15sp 视觉尺寸；点按目标 ≥ 44×44pt（移动）。
- 间距刻度尺比网页更收敛（界面密度天然更高），仍须保持比例阶梯。
- 基准栅格 8pt 网格对齐（允许 4pt 半格）。

### 字体
- 优先系统字体栈（SF Pro / Roboto / HarmonyOS Sans / MiSans 等），保证各端一致；特殊字体仅用于品牌展示区并备回退。

### 颜色
- token 分语义层：背景/表面/文本/边框/强调，另配 disabled/on-accent/状态色。
- 对比度同 WCAG AA；浅色上的强调色需同时保证"色弱可辨"（不只靠色相区分状态，加图标/文字）。

### 质量坑
- 禁把网页卡片布局直接搬进高密度数据界面——数据用行分隔与留白，不要格子化。
- 空态不是敷衍：给"如何开始"的引导；载入用骨架屏而非转圈。
- 表单 label 在输入框上方；错误内联、靠近触发控件。

### 交付检查
- [ ] 四态（默认/hover 或按压/载入/空+错误）齐全
- [ ] 点按目标尺寸达标；可访问性标签齐全
- [ ] 深色模式独立配色
- [ ] 密度符合风格档位，无元素挤压

## C. PPT / 演示与幻灯片

### 画布与单位
- 默认 16:9（13.333×7.5in 或 3382×1902px@254dpi）；除非放映环境明确 4:3。
- 文字以 pt 计：放映阅读最小 24pt，多数正文 28–36pt，标题 40–72pt（屏幕尺寸越大越要大）。
- 页边距：画布短边的 8–12% 起步（风格要求空旷则加大）。

### 字号档位与可读底线的化解规则（重要）
- 风格文件给的"字号阶梯比例"是介质无关原语（如 3.5:2:1:0.6），落 PPT 时按列换算，**但不得跌破 24pt 放映底限**。
- 若某档换算后 < 24pt，按优先级处理：① 把该档并入上一档（如辅助档并入正文档，用颜色/字重/字距区分而非字号）；② 或整体放大比例让最小档 ≥ 24pt（牺牲一点对比度差，换取可读）。
- **明确禁止**：为保留"精致的 0.6 小字"而把正文压到 < 24pt。投影下可读优先于比例还原。
- 通常 PPT 上实际用 3 档即可（标题 / 正文 / 数据标注），不必强行四档齐全。

### 字体
- 用可嵌入字体（嵌入到文件）或用系统安全字体；**禁止装了他机没有又不嵌入的字体**。
- 中文演示优先思源黑体/系统黑体；衬线/艺术字仅作氛围，正文回退黑体。

### 颜色
- 母版主题色 = 风格四层 token；投影仪普遍发灰/发白，背景与文字对比要比屏幕稿拉得更开。
- 避免大面积纯黑底 + 高饱和强调在暗环境投影时糊成一片。

### 材质与圆角基准（PPT）
- 风格文件的"曲率性格"（锋利/适中/圆润/极圆）是原语，落 PPT 给具体值：锋利=2–4pt，适中=8–12pt，圆润=14–20pt，极圆(胶囊)=28pt+ 或纯胶囊。
- 玻璃/磨砂面板：底色用比背景略亮的深灰阶 + 1px 半透明白边 + 内高光（模拟玻璃折射）；如 PPT 软件不支持 blur，用"浅色渐变 + 细边框"近似即可。
- 阴影用深色柔和投影，避免硬边黑影；强调色只做单点发光，别整页发光。

### 版式与内容纪律（本介质最大坑）
- 一页一个观点；禁满屏项目符号——要点改用图形化表达（大数字、图标、短句）。
- 图表/图直接可读：字号不小于正文下限，配色用风格强调色而非 Excel 默认。
- 动效克制：切换动画 ≤ 2 档速度差，禁每个元素飞入。

### 交付检查
- [ ] 每页标题能独立成句，页内要点 ≤ 5 条
- [ ] 最远座位也能读清最小文字（用"屏幕高度 ÷ 观看距离"粗估）
- [ ] 字体已嵌入或为系统字体；主题色统一
- [ ] 打印/导出 PDF 前检查分页断裂与溢出色块

## D. 平面 / 海报、封面与印刷物料

### 画布与单位
- 先问输出：数字屏显（RGB, px/pt）还是印刷（CMYK, mm, 300dpi，含 3mm 出血）。
- 版心与出血：安全内容距成品边缘 ≥ 5mm；背景色块延伸到出血线。
- 字号以 pt（数字）或 mm（印刷）；远距海报（如 1m 外观看）字号按观看距离 ×1/100 起步粗估。

### 字体
- 印刷前确认字体授权含"印刷/商用"；文字转曲（outline）或随文件打包字体。
- 中文字体体积大，交稿时说明字体清单，避免缺字替换。

### 颜色
- RGB 转 CMYK 后校样——屏幕看着亮的青绿/荧光色印刷会发暗。
- 专色/工艺（烫金、UV、压纹）在风格文件标注"可选工艺"，成本未知时只给建议不擅加。

### 版式纪律
- 平面没有滚动与交互：信息层级必须一次讲清——主视觉焦点、次信息、出处/细节三级，靠大小+位置+色彩三层差制造。
- 留白不是浪费是版式本身；拥挤海报的观感劣于留白不足的网页。

### 交付检查
- [ ] 出血、裁切标记、安全边距就位（印刷）
- [ ] 文字未贴边、未被图片遮挡；最小可读字号达标
- [ ] 颜色模型正确（RGB for 屏显 / CMYK for 印刷）
- [ ] 字体授权与嵌入状态明确

## E. 其他介质（长文档 / 邮件 / 社交图卡 / 数据大屏…）

通用翻译法：
1. 找到该介质的"阅读距离与分辨率"基准，据此换算字号下限；
2. 找到"画布/安全区"规范（如邮件 600px 宽、社媒 1080×1350 竖图、大屏 1920 起步且远距观看）；
3. 套用风格 token 的**比例与气质**，介质特有坑以官方设计规范为准（如邮件客户端不支持现代 CSS 时降级为表格布局）。

## F. 高级技法库（可选，提升成熟度）

> 吸收自业界成熟设计系统（taste 等）的**通用设计技法**。这些技法**本身是介质无关的设计语言**（不绑定任何框架），按需选用可让产出从"好看"提升到"精致、成熟"。
> 约定：技法只写**效果与用途**，不绑定 Tailwind/React 等框架；落地到具体介质时由介质映射表翻译。**克制使用**——一个界面用 1–2 个主力技法即可，滥用会变成炫技。

### 层叠与深度

- **嵌套容器（双层结构）**：把内容放进"外壳 + 内核"两层——外壳给背景/细边/大圆角/小内边距，内核给独立背景 + 内侧高光，形成"物理嵌件"般的精致感。常用于卡片、输入框、图块。
- **玻璃拟物（真毛玻璃）**：半透明 + 背景模糊 + 1px 内发光边（模拟边缘折射），不止 `backdrop-blur`。深色背景上效果最佳。
- **柔和扩散影**：极淡、大范围的投影（低透明度、高模糊半径），营造"悬浮"而非"发光"。取代默认硬阴影。

### 质感与纹理

- **噪点/胶片颗粒**：固定层（不随滚动）+ 低透明度（2–5%）的微弱噪点，模拟纸感/物理质感。**只用于固定背景层，绝不放在滚动容器**。
- **CRT 扫描线**：细密的横向重复渐变（2–4px 周期，极低透明度），用于军工/终端/复古科技风。
- **半调/1bit 抖色**：把图形或大衬线字转成网点纹理，制造"模拟降解"的复古印刷感。用 `mix-blend-mode` + 网点 SVG 叠加实现。

### 动效与交互（非静态介质）

- **自定义缓动曲线**：不用默认 `ease`，用自定义 `cubic-bezier`（如 `(0.32,0.72,0,1)`）模拟真实物体的惯性/重量感。
- **弹簧/磁性物理**：按钮吸附鼠标、按压缩放（`scale(0.98)`）的"物理按压"反馈。
- **交错入场（stagger）**：列表/网格项按序错开淡入（`animation-delay` 级联），而非同时出现。
- **按钮内嵌图标圈**：按钮的箭头/图标嵌在单独的小圆里（"按钮中按钮"），制造内部动势。
- **滚动插值入场**：元素进入视口时淡入 + 上移 + 轻模糊（`translateY + opacity + blur`），用 IntersectionObserver，禁 `window.addEventListener('scroll')`。

### 编排与网格

- **非对称 Bento 栅格**：不同大小的格子（col-span 变化）组成马赛克式布局，打破单调。移动端回落单列。
- **Z 轴层叠**：元素像卡片轻微重叠、带微小旋转（±2–3°），制造纵深。移动端去掉旋转与负边距。
- **超大留白（macro-whitespace）**：区块间距用超大值（如屏高 1/4 以上），让版面"呼吸"出高级感。

### 字体层叠

- **粗体 + 常规 + 细体混排**：同一家族内用极端字重差制造张力（巨型粗标题 + 纤细正文）。
- **衬线装饰字 + 无衬线正文**：编辑感标题用衬线，正文/界面用无衬线（排版杂志感）。注：本 skill 默认中文以无衬线为主，衬线仅作编辑/时尚氛围可选。
- **等宽数据字**：数字/代码/元数据用等宽字体，营造技术感。

> **⚠️ 极简克制（重要）**：极简/极净类风格**不要滥用字体混搭**。主力标题一句里最多 **2 种字重**（同家族的粗+细），**不要**再加第三种字体（如衬线装饰）——否则一句话凑 3 种字体，就失去极简的纯粹意义。衬线装饰仅用于"编辑杂志"这种**本就追求浓烈排版张力**的风格（bold 类）；极简类一律同家族靠字重差，字体的"种类"要克制。中文正文/英文用"中英文分工"（中文思源黑体、英文 Montserrat）是约定，不算堆砌。

### 如何使用

1. **按风格气质选主力技法**：如 dark-glass 用「玻璃拟物 + 柔和扩散影 + 交错入场」；editorial-calm 用「超大留白 + 粗常规混排 + 噪点」；bold-playful 用「Z 轴层叠 + 弹簧物理」。
2. **介质无关**：技法描述的是"效果"，具体实现（圆角值、模糊半径、缓动参数）由介质映射表翻译。
3. **克制**：每种风格最多选 1–2 个主力 + 少量点缀，避免炫技堆砌。
