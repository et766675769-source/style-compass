# 案例标注卡（case-card-template）

> 用途：蒸馏模式第 1 步。每个案例复制一张卡，填入下面字段。
> 填写要点：**区分"可迁移要素"与"介质特有要素"**——前者进入风格文件，后者只作参考不入库。
> 保存建议：按批存放 `assets/case-cards/case-<编号>-<介质>.md`，提炼完成后归档。

---

## 基本信息

- **出处 URL**：
- **作者 / 来源**：
- **授权状态**：（可否截图/复用于开源仓库？CC / 官网展示授权 / 仅私人研究 / 未知→默认不入库）
- **介质**：（网页 / 应用 UI / PPT / 海报 / 封面 / 品牌物料 / 其他）
- **案例快照位置**：（assets 路径或链接）

## 审美标注

- **气质标签（2–3 个）**：（例：编辑杂志感 / 贵气克制 / 暗色科技）
- **好在哪（1–2 句）**：画面焦点、情绪、第一眼记忆点
- **对照感言**：如果同类内容给 AI 默认做，会是什么样？差在哪？

## 可迁移要素（→ 进风格文件的量化特征）

| 维度 | 观察（尽量量化：比例/区间/气质） |
| --- | --- |
| 色彩 | 基底性格、主色数量、强调色饱和度档位、有无禁用色相 |
| 层级节奏 | 主标题与正文的体型差、张力靠字号还是字重还是字距 |
| 留白密度 | 粗略填充占比、区块间隔与大标题的比例感 |
| 对齐栅格 | 居中/左对齐/非对称；有无破格 |
| 字体气质 | 衬线/无衬线分工、字距行高性格 |
| 材质语气 | 曲率、线条、阴影的有无与分寸 |
| 图形语言 | 图标风格、图片调色统一性、纹理 |
| 一句话规则 | 把本案例压缩成一条可执行规范 |

## 介质特有要素（不迁移，仅参考）

- 该介质的画布/工艺/平台限制里，哪些是"只属于它"的？（例：海报的远距观看字号、PPT 的单页观点、网页的响应式）
- 若把本案例气质搬到另一个介质，最该保留/最该舍弃的分别是什么？

## 蒸馏去向

- 归入风格：`style-<气质名>.md`（提炼完成后填写）
- 状态：待归类 / 已入库
