# AI 味反模式清单（ai-tells）

> 用途：产出后逐条核对（应用模式第 5 步 / 第 6 步自检）；审查既有作品时也可作为审计表。
> 清单结构：每条 = 现象 → 为什么是 AI 味 → 替代做法。分「跨介质通用」「网页/UI」「PPT」「平面」四组。
> 维护约定：这是起步清单。你收集案例时若发现新的"一眼 AI"特征，追加进来并注明来源案例。

---

## A. 跨介质通用（所有产出必查）

- [ ] **占位内容**：Acme / John Doe / Lorem Ipsum / 99.99% / 123-456-7890。→ 用贴合场景的真实感名称、有零有整的数据（47.2%、+1 (312) 847-1928）。
- [ ] **假品牌名套路**：Xyzzzy、SmartFlow、NextGen 之类"启动器拼接词"。→ 结合内容语境造具体名字。
- [ ] **AI 文案腔**：Elevate / Seamless / Unleash / 赋能 / 重塑 / 一站式 / 助力。→ 用具体动词与可感知的结果。
- [ ] **纯黑 + 纯白硬撞**：`#000` 无细节大底、死白。→ 近黑/近白 + 一档灰阶过渡。
- [ ] **紫蓝 AI 色调**：亮紫渐变 + 深蓝底 + 光晕。→ 单一克制强调色 + 中性基底。
- [ ] **无意义渐变与发光**：为了"现代感"而加的渐变文字、霓虹光晕。→ 去掉或只留一处有语义的高光。
- [ ] **层次只有"大和小"**：所有强调都靠放大字号，缺字重/字距/色彩/留白配合。→ 多维度制造对比。
- [ ] **信息塞满无呼吸**：能塞尽塞、间距均匀无节奏。→ 主动留白，制造密度差。
- [ ] **三个等分卡片齐步走**。→ 非对称网格、错落布局或行分隔替代。
- [ ] **装饰无意义**：乱撒的星星/几何/emoji 点缀、与内容无关的插图。→ 每个装饰元素要么承载语义要么删除。

## B. 网页 / 应用 UI（代码类产出必查）

- [ ] **全套默认 UI 库皮肤**：shadcn/Material/antd 默认色与默认圆角直接出货。→ 换品牌 token、调曲率阴影，至少做到"不像模板"。
- [ ] **Inter/Roboto 无脑用 + 无字距策略**。→ 按风格文件选字体，标题给 tracking 决策。
- [ ] **状态只有默认态**：无 hover/active/载入/空/错误。→ 补齐四态。
- [ ] **Emoji 当图标**。→ 换成风格一致的图标系统。
- [ ] **裸 Unsplash 占位图**。→ 可靠占位（picsum seed/自绘 SVG）+ 调色统一。
- [ ] **`h-screen` 首屏 + 移动端跳动**。→ `100dvh`。
- [ ] **动画只动 layout 属性 / 滚动监听做视差**。→ 只动 transform/opacity；入场用交互动画库或 IO。
- [ ] **假数据一眼假**：头像全是同一人、用户全叫 Sarah/王小明、数字全是整数。→ 制造有机差异。

## C. PPT / 演示（必查）

- [ ] **满屏项目符号**（AI 最爱的要点轰炸）。→ 一页一观点，图形化表达。
- [ ] **小于 24pt 的正文**。→ 放大到放映可读下限，删内容而不是缩字号。
- [ ] **每页塞一整段方案**。→ 拆页，演讲者备注放细节。
- [ ] **Excel 默认图表配色**。→ 主题色重绘，去掉网格线/图例堆叠。
- [ ] **每元素都飞入的动画**。→ 动效只服务观点切换，全篇一个节奏。

## D. 平面 / 海报（必查）

- [ ] **海报做成网页截图**：信息堆叠无焦点、无阅读路径。→ 先定主焦点，再排次级，最后出处细节。
- [ ] **文字贴边或被裁**。→ 安全边距与出血检查。
- [ ] **RGB 荧光色直接印刷**。→ CMYK 校样，警惕青色/荧光绿发暗。
- [ ] **字体在别人机器上变默认体**。→ 嵌入/转曲/给字体清单。
- [ ] **正文小到不可读还自认精致**。→ 远距观看字号下限优先于美观。

---

## 用法补充

- 核对时不是"存在即删"：判断标准是**它是否无目的地出现**。有语义的强调色、有意为之的破格不算 AI 味。
- 若某风格文件特供的反模式与此冲突，以风格文件为准并回填本清单注明原因。
