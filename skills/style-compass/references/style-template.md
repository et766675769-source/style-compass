# 风格规范母版（style-template）

> 用途：蒸馏模式下，每个"视觉气质"生成一份 `references/style-<气质名>.md`。
> 填写规则：
> 1. 本文件的 **核心字段全部介质无关**——用比例、区间、气质、边界条件表述，禁止出现任何介质的写死数值（如"圆角 12px"、"左对齐 120px 边距"、字号 pt/px 具体值）。唯一例外是介质映射表（第 9 节），那里允许出现具体参数。
> 2. 每条规范必须**可执行可核对**。写"高端感"不行，写"大留白 + 弱网格 + 单一主色 + 强对比标题"才行。
> 3. 复制本文件为 `style-<气质名>.md` 后，删除本说明块。
> 4. 自检：完成后面向"网页 + PPT + 海报"三种介质各默渲一遍，气质成立才算完成。

# Style: <气质名>（如 editorial-calm / dark-tech / soft-premium）

## 1. 气质一句话

一句话让任何 Agent 抓住核心，例："杂志编辑感的留白型版面，文字大而静，画面空旷、克制、昂贵。"

## 2. 适用信号（何时推荐这套风格）

- 触发词/场景：……
- 适合的受众与情绪：……
- 明确不适用的场景（宁可拒绝也不硬套）：……

## 3. 色彩宪法（介质无关层）

- **中性基底**：底色性格（纯白/暖白/米色/炭黑…）+ 文字用色（拒绝纯黑 `#000`，给"近黑"区间如 #111–#2A2A2A 的气质说明）
- **表面层级**：卡片/浮层的明度差方向（浅底深字体系：表面略深于背景；深色体系：表面略亮于背景）与分隔方式（线分隔/面分隔/纯留白）
- **强调色**：数量上限（默认 1）、饱和度档位（高/中/低 + 何时用高饱和）、明度区间、使用规则（只给交互与语义，不给大区块）
- **禁用色相**：本风格拒绝的色相或组合（例：AI 紫蓝、荧光渐变）
- **明暗双模式**：是否必须支持深/浅两套；若是，给出转换规则（不可简单反色，需重新配明度）

## 4. 对比节奏（层级 = 介质无关的核心）

- **字号阶梯比例**：显示:标题:正文:辅助 ≈ ？（例 3.5 : 2 : 1 : 0.75）
- **字重使用纪律**：粗/常规/细分别在什么层级用；标题靠什么制造张力（字号差 or 字重差 or 字距）
- **行高与字距性格**：紧/松；标题收紧、正文放宽的档位描述
- **正文行宽**：舒适阅读的字符数区间（40–75 字符为常识基准，除非风格刻意反其道）
- **字体气质**：衬线/无衬线/等宽如何分工；具体字体名只写"候选 + 授权提示"，见第 9 节介质表

## 5. 留白与呼吸纪律

- **内容密度档位**（画廊级 <40% 填充 / 日常 40–60% / 高密 >60%——按气质选一档为主）
- **区块间距相对值**：以大字号为基准的比例（如"大标题的 1–2 倍作为区块间隙"）
- **关键元素周边留白最低要求**：什么元素绝不能被挤压（标题、CTA、图表）
- **分页/分屏的呼吸节奏**：多页或长页时，"密集页 ↔ 空旷页"是否需要交替（避免全程同密度）

## 6. 栅格与对齐性格

- **对齐范式**：居中 / 左对齐为主 / 非对称错落 / 网格对齐（选一为主，写清例外规则）
- **栅格情绪**：是否允许破格（元素有意越出栅格）、何时允许
- **模块组织**：分组靠什么（留白 > 边框 > 底色，按气质排优先级）
- **版面分割**：版面比例偏好（如黄金/三等分/信息侧栏等，用比例词，不写 px）

## 7. 材质与语气

- **曲率性格**：锋利（近乎直角）/ 适中 / 圆润（克制）/ 极圆（胶囊，慎用）——给出何时启用哪种
- **线条**：是否需要细线分隔；线的透明度/颜色气质（比底色深一档的灰，而非纯黑）
- **阴影**：无影 / 极淡扩散影 / 硬边投影——选一档为主，给出分寸描述（"只出现在需要抬升的交互层"）
- **图形语言**：图标风格（线型粗细/圆角头/填充）、插画气质、图片裁切与调色（饱和度/色调统一性）、纹理颗粒

## 8. 动效与语气（可选节）

按"静 / 缓 / 强"三档描述本风格动效上限：入场方式、过渡时长感知（快/慢）、是否禁止持续动画。非交互介质（海报/平面）此节注明"仅限静态"。

## 9. 介质映射表（允许写具体数值的地方）

介质无关的 token 在这里翻译成各介质参数。给"本风格的落点 + 参考区间"，不是通用默认值。

| token（上文章节） | 网页/CSS | 应用 UI | PPT/演示 | 平面/海报 |
| --- | --- | --- | --- | --- |
| 色彩宪法 | 背景/文字/强调的色值示例（HEX 区间）+ Tailwind 落点 | 与网页列相同的 token，加 UI 态（disabled 等） | 幻灯片背景/正文/强调 + 母版主题色 | 印刷四色近似 + 出血/专色提示 |
| 对比节奏 | 字号 px/clamp 区间 | pt/sp 区间 | 字号 pt + 最小可读字号 | 字号 pt/mm + 远距观看字号 |
| 留白纪律 | 断点 + 容器宽 + 区块间距 px | dp/sp 间距刻度 | 页边距比例（如画布宽 8–12%） | 出血距 + 版心比例 |
| 栅格 | CSS Grid/流式 | 组件间距系统 | 12 列网格 + 版式母版 | 三分/网格 + 裁切标记 |
| 字体 | 字体栈 + webfont 来源（OFL 优先） | 系统字体栈 | 可嵌入字体 + 回退字体 | 可商用字体 + 授权备注 |
| 材质/图形 | 圆角/阴影/边框 CSS | 组件圆角与层级 | 图形占位规则 | 工艺提示（烫金/UV/专色，可省） |
| 反模式差异 | 本风格在 CSS 层的禁用写法 | 本风格在 UI 态的禁用写法 | 本风格在版式层的禁用写法 | 本风格在平面层的禁用写法 |

> 介质表填不满没关系，空白列说明"沿用通用映射"（见 [medium-mapping.md](medium-mapping.md)），但每列必须至少有一条**属于本风格的决策**。

## 11. 自检清单（交付前打勾）

- [ ] 主视觉焦点明确，阅读顺序 主→次→辅 成立
- [ ] 色彩 ≤ 上限色数、无禁用色相、对比度可读
- [ ] 字号阶梯符合本节比例，正文行宽达标
- [ ] 留白密度符合本节档位，关键元素未被挤压
- [ ] 对齐统一（破格是故意而非失误）
- [ ] 材质语气一致（圆角/阴影/线条全篇一个系统）
- [ ] 无本风格反模式、无通用 AI 味（过 ai-tells.md）
- [ ] 已在目标介质的"交付检查"过一遍（medium-mapping.md）
- [ ] 介质特有的坑（PPT 满屏文字/印刷对比损失等）已规避
